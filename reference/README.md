# Rumla Release baseline (read-only reference)

This directory was extracted from the author-published .7z **for comparison**. The CI build MUST NOT download or use the original .7z as an input.

manifest.json records each installed SD file's SHA256, size and path.
config-reference/ contains only small human-readable text configs for research. Do not assume all of them are safe to copy to a different firmware version.

Captured 277 installed files and 47 text configs.
